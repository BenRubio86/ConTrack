# ConTrack V4 Preview

This branch is reserved for the HangingSense UX refresh before anything is merged to `main`.

Planned/implemented preview features:
- Higher-contrast HangingSense light/dark visual system
- Large one-handed contraction timer and bottom navigation
- Pain-intensity control panel (slider + descriptive labels), not number-button picking
- Add Event flow for pee, pain/discomfort, waters/fluid, bleeding, and other notes
- Optional event photo capture stored locally/offline
- Unified chart for duration, interval/frequency, pain intensity, and event markers
- Working 1h / 3h / Day / All chart ranges
- Unified contraction + event history with cumulative averages and photo thumbnails
- Shareable self-contained HTML report with chart, legend, timeline table, events, pain intensity, and embedded photos
- New-session flow that offers local archiving or a photo-inclusive backup before starting a new session
- Existing V1/V2/V2.3 contraction data remains compatible

The live GitHub Pages site is intentionally not changed until the preview is tested.
